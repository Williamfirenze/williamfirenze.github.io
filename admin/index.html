Admin

Not a security boundary — this is a static site. It keeps the panel out of the way, nothing more.

Knowledge base

The runbooks the chat answers from. Everything happens in your browser — when you're done, export kb.json and upload it to the repo.

Access codes

One code per colleague. The exported file holds only SHA-256 hashes — the codes themselves never reach the repo.

Copy the code when it appears. It's shown once, then only its hash is kept in the export. A copy stays in this browser so you can look it up later, but it won't follow you to another machine.

How to create a KB

The assistant in the chat isn't a language model: it doesn't guess. It finds the right runbook and shows the section that was asked for. So the quality of the answers is the quality of these fields.

Open any Claude chatAnywhere — the app, the web, the phone. It doesn't need to know anything about this site.
Paste the prompt belowIt's the whole block. Copy it with the button.
Underneath, tell it the case however it comes outRough notes, a rant, a paste from the ticket. What you did, what didn't work, the exact commands. The messier the input, the more it will ask you back — that's the point.
Check _missingIt's the list of things you didn't answer. Either answer them and regenerate, or fill them in by hand here. An article with holes still works, it just gets found less often.
Copy the JSON and import itKnowledge base tab → Paste JSON from Claude → Import.
Export and uploadExport kb.json, then drop the file into data/ in the repo. Live in about a minute.

What makes an article findable

      

        
codes — every error code mentioned, uppercase (ORA-01555). This is the strongest signal there is: a code match beats everything else.

        
keywords — the words you'd actually type at 3am under pressure. Wrong ones, Italian ones, half-remembered ones. Five to twelve.

        
symptoms — what the person in trouble is looking at. They rarely know the cause; they know what they see.

        
command on each step — this is what gets copied at 3am. Exact, or flagged as approximate in note.

      


      
What it can't do

      

        
It won't reason about a case that isn't written down, it won't combine two runbooks into a new answer, and it won't improvise. If it isn't in the knowledge base, it says so and points to your email — which is the honest behaviour, and better than a confident wrong answer at 3am.
